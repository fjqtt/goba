# Cho elementary: полный GNU Go audit

Проверено 2026-09-16 на Apple M1 Pro, GNU Go 3.8 Owl.

## Входы

- Позиции: `/private/tmp/cho-1.sgf`, 900 задач, `sha256:2667ddc1f73d9256820a598427ae212be78874c33932c5baf99d97793d8df432`.
- Community printable key: `/private/tmp/cho-go-problems.json`, 900 записей, `sha256:742af89d57931488e6f3b6e90732481a94809bc1a3b8f3fd386f5e2ff72f416d`.
- Exact setup match: 845 задач. Ещё 55 не запускались в этом audit, потому что постановки источников различаются.
- В ключе для 723 связанных задач есть одна последовательность длиной 1–9 ходов. Для 122 задач доступны только несколько альтернативных первых ходов.

## Что сопоставлялось

1. Каждый ход printable line независимо проигрывался через `RulesAdapter` с `ld-v1`; все 845 доступных записей легальны в соответствующей исходной позиции.
2. Для каждой связной группы запускались `owl_attack`/`owl_defend` и `owl_does_*` для всех известных первых ходов.
3. Для каждой подходящей target-группы сохранялся полный output `--decide-owl`.
4. В дереве рассматривалась только ветка с фактическим цветом первого хода; диагностическая ветка «другая сторона ходит первой» исключалась.
5. Вся авторская последовательность искалась как непрерывный путь, а каждое ребро всех рассматриваемых ветвей повторно проигрывалось через `RulesAdapter`.

## Результат

| Класс | Задач | Значение |
|---|---:|---|
| Full line + всё выбранное Owl tree легально | **305** | Вся доступная авторская последовательность найдена, незаконных ветвей в выбранном дереве нет |
| Вся source line присутствует, но в других ветвях дерева есть нарушения `ld-v1` | **69** | Линия совпала; сырое дерево целиком принимать нельзя |
| Совпала только часть продолжения | **73** | Нужно расширение или другой solver/target review |
| Подтверждён только первый ход / не покрыты все root alternatives | **392** | Дальнейшая авторская последовательность отсутствует в выбранном Owl tree |
| Все альтернативные root moves покрыты и дерево легально | **1** | Для задачи с несколькими первыми ходами покрыт весь доступный ключ |
| Ни одна target-группа не приняла известный root move | **5** | Problems 193, 214, 724, 804, 887 |

Полный source path найден в **374 из 723** записей с последовательностью. У 69 из них другие ветви выбранного Owl tree нарушают `ld-v1`, поэтому строгий итог — 305. Для 122 multi-root записей все известные первые ходы присутствуют в выбранном дереве у 6 задач, но только у одной дерево полностью легально.

В машинном отчёте 69 полных линий с незаконными соседними ветвями и 73 неполных продолжения объединены в консервативный статус `partial-line-match` — всего 142.

GNU Go принял все известные root moves через `owl_does_*` у 830 задач, часть root moves у 10 и ни одного у 5. Это шире, чем явное дерево: положительный GTP check не гарантирует, что каждый ход будет материализован `--decide-owl`.

## Деревья и нарушения

- Сохранено **3 327** SGF trees для подходящих target-групп.
- Ни один solver process/tree export не упал.
- 459 задач имеют дополнительные root moves хотя бы в одном candidate tree. Они остаются `unclassified`, пока не проверены terminal semantics.
- У 189 задач хотя бы одно candidate tree содержит ветку, не проходящую независимый replay; у выбранного дерева — 134 задачи.
- Нарушения в raw Owl output: 992 `wrong-turn` и 7 663 `superko` edges. Это подтверждает, что diagnostic Owl tree нельзя напрямую превращать в клиентское дерево решений.
